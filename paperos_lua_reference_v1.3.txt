PaperOS v1.3 — Lua API Reference
=====================================================================
Board: ESP32-S3FN8 — NO PSRAM (N8 = flash only, no R suffix). os.psram()
always returns 0, this is correct, not a bug.

This supersedes the v1.2 reference. Everything from v1.2 still applies
except where noted below under "CHANGED IN v1.3". No app-facing command
was removed — os.*/io.*/net.*/gpio.*/disp.*/key.*/sound.*/timer.*/ui.*/
store.*/json.*/bit.*/i2c.*/term.* are all unchanged and still there.
What changed is Lua's own standard library underneath them, and how
WiFi is handled — both explained below.

=====================================================================
CHANGED IN v1.3
=====================================================================

1) WiFi is now OFF by default while the Lua app is open, and comes
   back on demand.

   Why: WiFi's radio + lwip/mbedTLS buffers permanently occupy roughly
   40-70KB of this board's free heap for as long as it's connected -
   on a board with no PSRAM, that alone was often the difference
   between "a script has room to run" and os.heap() reading a
   crippling 20-30KB before a script had allocated a single byte.
   Most Lua scripts (drawing, GPIO, math, games) never touch net.* at
   all, so from v1.3 onward:

   - Opening the Lua app drops WiFi if it was connected (same thing
     myAI already did for its ~83KB model cache, same reason).
   - net.get(), net.post(), net.connect(), and net.scan() all bring
     WiFi back up automatically using the already-saved network
     credentials the first time any of them is actually called - you
     do NOT need to call net.connect() first "just in case" anymore.
     The first such call in a session may take a moment longer (up to
     ~4s) while it reconnects; every call after that is instant, same
     as before, since WiFi then just stays up for the rest of the
     session.
   - Closing the Lua app restores WiFi to whatever it was before you
     opened Lua.

   Net effect for scripts: nothing to change in how you write them.
   os.heap() at the Lua prompt (before running anything) should now
   read noticeably higher than it did on v1.2 if your board was
   WiFi-connected beforehand.

2) Lua's own standard library got smaller (real, permanent RAM saved
   for the whole session, not just reclaimed-when-needed like WiFi
   above):

   REMOVED (real Lua stdlib, not this OS's os.*/io.*/net.*/etc, which
   are untouched):
     - package.*  — require() here has always been a fully custom
       function; the real package.loaded/searchers/path/cpath tables
       were dead weight from the start.
     - the REAL os.* and io.* Lua libraries — both get their global
       name immediately overwritten by this OS's own os.*/io.* tables
       (see below), so the real ones were never reachable to begin
       with. This includes the real io.stdin/stdout/stderr file
       objects, which is also why the v1.2 patch note about those
       being set to nil made sense - the real ones were already
       thrown away by that point.
     - utf8.*  — real capability, but nothing in this OS's documented
       API used it.
     - debug.*  — same: real capability, unused here. Note that the
       interrupt/Ctrl+C mechanism does NOT depend on this - it uses
       lua_sethook() directly (a core Lua C function), not the
       Lua-visible debug.sethook() wrapper, so Ctrl+C still works
       exactly as before.

   KEPT: base (_G: print, pairs, ipairs, tostring, tonumber, pcall,
   error, setmetatable, type, ...), string.*, table.*, math.*,
   coroutine.*.

   If a script calls package.*, real os.*/io.* (as opposed to this
   OS's own), utf8.*, or debug.*, it will now get a clean "attempt to
   index a nil value" error instead of silently working. This OS's
   own os.*/io.*/net.*/etc. tables are completely unaffected - only
   the underlying real Lua libraries those functions don't need are
   gone.

3) New: os.stack()
   -> number, bytes of the Lua task's 16KB stack that have NEVER been
      touched since this Lua session started (uxTaskGetStackHighWaterMark,
      converted to bytes). This is the safe way to answer "can the
      16KB task stack be made smaller": run the heaviest/most
      recursive script you actually intend to use, then check
      os.stack() - whatever it reports has genuinely never been
      needed even once. The stack size itself was NOT changed in
      v1.3 - shrinking it without measuring first risks silent
      stack-corruption crashes on deep recursion, which is worse than
      the RAM it would save, so this is left as a measurement tool,
      not applied automatically.

=====================================================================
MEMORY MODEL — READ THIS FIRST (updated for v1.3)
-------------------------------------------------------------------
- os.heap()   -> ESP.getFreeHeap(): whole-board free SRAM. As of v1.3
  this reads noticeably higher at Lua startup than it used to, IF the
  board was WiFi-connected before you opened the app - see change #1
  above. It's still whole-board heap, not Lua's own usage - see
  os.luamem() for that.
- os.luamem() -> used, limit: Lua's OWN sandboxed heap via a custom
  allocator, hard-capped at LUA_HEAP_LIMIT_BYTES = 96 * 1024 (98304).
  This is a SEPARATE budget carved out of the same physical SRAM as
  os.heap(). Going over it raises a normal Lua "not enough memory"
  error -- IF the failure is caught cleanly. See BUG-1 below: it isn't
  always. Because real free board heap is now typically higher (see
  change #1), this 96KB soft cap is more likely to actually be the
  first thing a heavy script hits, rather than real system OOM getting
  there first - which is the point of having a soft cap at all.
- os.stack() -> see change #3 above. New in v1.3.
- With SD mounted, board free heap drops by ~27KB immediately (FAT/sector
  buffers), before writing anything. Confirmed by measurement.
- Full-screen canvas (240x135 RGB565 double buffer) permanently reserves
  ~63KB of SRAM whenever a graphical app (incl. the Lua terminal) is open.
- WiFi, when connected, costs roughly another 40-70KB - see change #1.
  As of v1.3 this is NOT paid while the Lua app is open unless a
  script actually uses net.*.
- Real headroom for scripts is still small on this no-PSRAM board -
  it's just less small than it was on v1.2, specifically for scripts
  that don't touch the network. Budget accordingly regardless.
- RULE OF THUMB: any loop doing 50+ allocations (string concat, table
  creation, json.encode/decode, etc.) should call collectgarbage()
  every ~30-50 iterations. Confirmed empirically to prevent BUG-1 below.
- NOTE: TLS/HTTPS handshakes still fail due to Out-Of-Memory on this
  board even with the extra headroom from change #1 - mbedTLS's own
  handshake buffers alone need more than is realistically available
  here. Use plain HTTP only for net.get/net.post.

=====================================================================
KNOWN BUGS (confirmed against source / on-device testing)
-----------------------------------------------------------
Unchanged from v1.2 - still all relevant, none were touched in v1.3:

BUG-1 [confirmed, reproducible]: json.encode()/json.decode() can SILENTLY
  return corrupted data instead of erroring when the board is under heap
  pressure (encoder uses Arduino String += with no malloc-failure check).
  WORKAROUND (safe today): call collectgarbage() every ~30-50 json calls
  in any loop, especially with SD mounted and heap already low.

BUG-2 [confirmed]: os.gc() returns ESP.getFreeHeap() (whole-board heap),
  NOT Lua memory usage. Name is misleading -- use os.luamem() for actual
  Lua heap usage.

BUG-3 [confirmed]: disp.rgb(r,g,b) returns 0 if called with no active
  canvas (g_lcanvas == nullptr). Only call disp.rgb() from a context
  where a graphical app/canvas is active.

BUG-4 [confirmed]: fs.mkdir(path) returns false both when the directory
  already exists AND on a genuine I/O error. Check fs.exists(path) first
  if you need to know which case you're in.

BUG-5 [confirmed]: json.decode() raises a hard Lua error (luaL_error) on
  invalid JSON instead of returning nil+message. Always wrap in pcall():
    local ok, result = pcall(json.decode, str)

BUG-6 [confirmed]: run(path) swallows script errors (prints to terminal,
  execution just stops) while dofile(path) propagates them via lua_error.
  A missing file is silent with run() but errors with dofile().

BUG-7 [by design, documented in source]: require(name) caches the loaded
  module PERMANENTLY for the life of the Lua session. Editing a .lua file
  on SD and calling require() again returns the OLD cached table. To
  force a reload, use dofile() instead of require(), or reboot the device.

QUIRK: fs.ls(path) returns NOTHING (0 values) unless called with a
  second argument = true: fs.ls("/sd", true) returns a table of
  {name=, dir=, size=} entries. fs.ls("/sd") alone only prints to the
  on-screen terminal.

QUIRK: sound.play() and net.scan() block the Lua thread while running
  (up to their timeout), though both are interruptible via Ctrl+C.

QUIRK: SD file access can intermittently report "file not found" on the
  very first run() immediately after copying a new file onto the card.
  Retry - it typically works the 2nd time.

=====================================================================
os.*
=====================================================================
os.clock()                 -> number, seconds since boot (millis()/1000)
os.time()                  -> number, seconds since boot
os.millis()                -> number
os.micros()                -> number
os.heap()                  -> number, ESP.getFreeHeap() [see BUG-2 and
                               change #1 above]
os.psram()                 -> number, always 0 on this board (no PSRAM)
os.luamem()                -> used, limit  (limit is fixed 98304)
os.stack()                 -> number, bytes of the 16KB task stack never
                               touched this session [NEW in v1.3]
os.gc()                    -> number [see BUG-2: NOT lua mem]
os.cpu()                   -> number, CPU freq MHz
os.flash()                 -> number, flash chip size bytes
os.sketchsize()            -> number, current sketch size bytes
os.core()                  -> number, FreeRTOS core id running this code
os.date()                  -> string
os.difftime(t2,t1)         -> number (t2-t1)
os.remove(path)            -> true | nil,"remove failed"
os.rename(a,b)              -> true | nil,"rename failed"
os.apps()                  -> table, list of installed apps
os.getenv(name)            -> always nil (stub)
os.tmpname()               -> string "/tmp_<millis>"
os.exit()                  -> same as os.home(), no return
os.launch(name)            -> boolean (queued only, ASYNC -- see below)
os.home()                  -> no return, ASYNC (see below)
os.bright(0-100)           -> sets display brightness (percent), no return
os.reset()                 -> ESP.restart(), does not return
os.frameTime()             -> number, seconds since previous call (0.0 first call)

os.launch()/os.home() are ASYNCHRONOUS: they queue the app switch for the
next tick on core0. Code immediately after os.home() WILL still execute.

Note: this is this OS's OWN os.* table, unrelated to (and unaffected by)
the real Lua os.* library being dropped in v1.3 - see change #2 above.

=====================================================================
fs.*   (path prefix "/sd" or "/SD" -> SD card, otherwise -> LittleFS)
=====================================================================
fs.exists(path)            -> boolean
fs.read(path [,maxbytes])  -> string | nil,"not found"   (default max 8192)
fs.write(path,data[,append])-> true,bytes_written | false,"open failed"
fs.rm(path)                -> boolean
fs.mkdir(path)              -> boolean [see BUG-4]
fs.size(path)               -> number bytes, or -1 if can't open
fs.rename(from,to)          -> boolean
fs.copy(from,to)            -> true | false,"cannot open source"
fs.ls([path="/sd"][,asList])-> table if asList==true, ELSE prints to
                               terminal and returns NOTHING [see QUIRK]
fs.free()                   -> number, free bytes on the FS
fs.total()                  -> number, total bytes on the FS

=====================================================================
io.*  /  file objects   (this OS's own - see change #2 above)
=====================================================================
io.open(path, mode)        -> file | nil,err   modes: r w a r+ w+ a+
io.write(...)              -> writes to the ON-SCREEN TERMINAL, NOT a file
io.read()                  -> always nil (stub, no stdin)
io.lines(path)             -> iterator function
io.stdin / io.stdout / io.stderr -> nil (not file objects - indexing
                               them, e.g. io.stdout:write(...), raises
                               a clear "attempt to index a nil value")

file:read()                -> one line (no \r\n), or nil at EOF
file:write(s)               -> writes string
file:lines()                -> iterator
file:seek(...)              -> standard seek
file:flush()                -> returns self
file:close()                -> safe to call twice, closes underlying File
(file objects also close automatically via __gc if abandoned, but don't
rely on this under heap pressure -- always call :close() explicitly)

=====================================================================
net.*   (WiFi handling changed in v1.3 - see change #1 above)
=====================================================================
net.ip()                    -> string
net.mac()                   -> string
net.ssid()                  -> string (empty if not connected)
net.rssi()                  -> number
net.status()                -> boolean, true if WL_CONNECTED (will read
                                false right after opening the Lua app if
                                WiFi was dropped per change #1, until
                                something brings it back up)
net.scan([asList])          -> asList=true: table of {ssid,rssi,ch}
                                else: prints to terminal. Brings WiFi's
                                radio back on first if it was off. BLOCKS
                                up to 10s (interruptible via Ctrl+C).
net.connect(ssid[,pass])    -> attempts connect (also un-does WiFi being
                                fully powered off, if it was)
net.disconnect()            -> no return
net.get(url)                -> code,body | nil,"not connected"/"begin failed"/err
                                Automatically reconnects using saved
                                credentials first, if needed [v1.3].
                                HTTP ONLY - HTTPS URLs fail (RAM).
net.post(url[,body][,contentType]) -> code,body | nil,err
                                Same auto-reconnect as net.get [v1.3].
                                default contentType "application/json"
                                HTTP ONLY - HTTPS URLs fail (RAM).

=====================================================================
gpio.*
=====================================================================
gpio.mode(pin, mode)        -> mode: 0=INPUT 1=OUTPUT 2=INPUT_PULLUP
                                3=INPUT_PULLDOWN. Invalid mode silently
                                does nothing (no error raised).
gpio.write(pin, val)        -> digitalWrite
gpio.read(pin)               -> digitalRead, 0/1
gpio.aread(pin)               -> analogRead
gpio.awrite(pin, val)         -> analogWrite (PWM)
gpio.tone(pin, freq[, duration=0]) -> tone()
gpio.notone(pin)              -> noTone()

gpio.mode()/gpio.write()/gpio.awrite()/gpio.tone() CHECK if a pin belongs
to system hardware (keyboard, SD, display, audio/mic/IR) and raise a
clear Lua error instead of silently corrupting hardware state.
Reserved pins: 3,4,5,6,7,8,9,10,11,13,15 (keyboard), 12,14,39,40 (SD),
33,34,35,36,37,38 (display/RGB), 41,42,43,44,46 (audio/IR/mic).
G1/G2 (Grove) are intentionally unrestricted.

=====================================================================
disp.*  (raw canvas drawing -- most no-op silently if no canvas is open)
=====================================================================
disp.cls()                  -> clears the TEXT TERMINAL (not the canvas)
disp.print(s)                -> prints a line to the text terminal
disp.bright(0-255)            -> display brightness, raw 0-255 range
                                (note: os.bright() takes 0-100 instead!)
disp.w() / disp.h()           -> screen width/height: 240 x 135
disp.rgb(r,g,b)                -> RGB565 color int [see BUG-3]
disp.clear([color=0])          -> fillSprite; no-op if no canvas
disp.pixel(x,y[,color])        -> no-op if no canvas
disp.line(x1,y1,x2,y2[,color]) -> no-op if no canvas
disp.rect(x,y,w,h[,color])     -> outline rect; no-op if no canvas
disp.fillRect(x,y,w,h[,color]) -> no-op if no canvas
disp.circle(x,y,r[,color])     -> outline; no-op if no canvas
disp.fillCircle(x,y,r[,color]) -> no-op if no canvas
disp.triangle(x1,y1,x2,y2,x3,y3[,color]) -> no-op if no canvas
disp.text(x,y,str[,color][,size=1]) -> no-op if no canvas
disp.clip([x,y,w,h])           -> no-op if no canvas; call with 0 args to
                                  clear the clip rect
disp.flip()                    -> pushes canvas to screen; no-op if no canvas
(out-of-range coordinates do NOT crash - LGFX clips/ignores silently)

key.justPressed(char)        -> boolean
key.released(char)           -> boolean
key.any()                    -> boolean, any key currently down
key.poll()                    -> forces a keyboard state poll, no return

sound.*
=====================================================================
sound.tone(freq[, ms=200])   -> plays tone, no return
sound.note(name[, ms=300])    -> e.g. "C4"; silently no-ops on bad name
sound.stop()                   -> stops playback
sound.volume(0-255)             -> sets speaker volume
sound.play(path)                -> WAV ONLY. BLOCKS the Lua thread until
                                  playback finishes or is interrupted.

=====================================================================
timer.*
=====================================================================
timer.every(ms, fn)          -> id (number, index into internal array)
timer.after(ms, fn)           -> id
timer.cancel(id)               -> no return; safe to call twice / on an
                                  already-cancelled id
(fn must be a function - passing a non-function raises a Lua error
immediately)
(timer.every()/timer.after() are safe to call FROM INSIDE a timer
callback - the iterator-invalidation bug from earlier sessions is fixed)

=====================================================================
ui.*  (blocking modal dialogs -- all require an active canvas)
=====================================================================
ui.confirm([msg="Exit to home?"]) -> boolean. Returns false immediately
                                     if no canvas (does NOT block/wait).
ui.toast(msg[,color])              -> no-op if no canvas; instant, no
                                      auto-dismiss timer, non-blocking
ui.inputText([prompt="Input:"])     -> string. Returns "" (NOT nil) if no
                                      canvas -- indistinguishable from a
                                      real empty user input.
ui.progress(percent)                 -> draws a progress bar, no-op if
                                      no canvas
ui.menu(items_table)                  -> selected 1-based index, or nil
                                      if cancelled/no canvas/no items.
                                      BLOCKS until ENT/`/quit. items_table
                                      must be a Lua array of strings.

=====================================================================
store.*  (NVS-backed persistent key/value, survives reboot)
=====================================================================
store.get(key[,default=""])   -> string
store.set(key, value)          -> no return (value is coerced to string)
(each get/set opens+closes NVS internally - avoid calling store.set() in
a tight loop, NVS writes are relatively slow and wear-sensitive flash)

=====================================================================
json.*
=====================================================================
json.encode(value)            -> string. Tables with contiguous integer
                                 keys 1..n encode as JSON arrays, anything
                                 else as objects. [see BUG-1 under load]
json.decode(str)                -> value | RAISES on invalid JSON [see
                                 BUG-5]. Always wrap in pcall().

bit.band(a,b) / bit.bor(a,b) / bit.bxor(a,b) / bit.bnot(a)
bit.lshift(a,n) / bit.rshift(a,n) [logical, unsigned] / bit.arshift(a,n) [arithmetic]
bit.tohex(n[,digits=8])        -> hex string, uppercase, zero-padded

i2c.*
=====================================================================
i2c.begin([sda,scl])           -> true. Auto-called by write/read.
i2c.scan()                      -> table of found addresses (may be empty)
i2c.write(addr, data)             -> ok(boolean), err_code(number)
i2c.read(addr, nbytes)             -> string (raw bytes read)

term.*
=====================================================================
term.dump()                    -> table of current terminal lines (array)
term.dumpText()                  -> same, as a single newline-joined string

=====================================================================
require / run / dofile / print / sleep / loop  (globals)
=====================================================================
require(name)                  -> cached module table [see BUG-7].
                                 Searches /sd/lua/<n>.lua, /sd/<n>.lua,
                                 /<n>.lua, /sd/lib/<n>.lua in that order.
                                 Circular require raises a clear error.
                                 Fully custom - does NOT use (or need)
                                 the real Lua package library, which is
                                 why that library was dropped in v1.3.
run(path)                        -> loads+executes; on error, PRINTS to
                                 terminal and returns [see BUG-6].
dofile(path)                      -> loads+executes; missing file or
                                 syntax/runtime error RAISES [see BUG-6].
print(...)                        -> writes to the on-screen terminal
sleep(ms)                          -> blocking delay (ticks timers every
                                    20ms, Ctrl+C interruptible)
loop(fn)                            -> runs fn every frame; fn returning
                                    false stops the loop. Correctly
                                    clears the interrupt flag when it
                                    stops via Ctrl+C, so a sleep()/
                                    net.get()/json.decode() call right
                                    after won't falsely raise
                                    "interrupted".

=====================================================================
NOT AVAILABLE (real Lua stdlib, intentionally not loaded - see change #2)
=====================================================================
package.*, the real (pre-override) os.*/io.*, utf8.*, debug.* - indexing
any of these now raises "attempt to index a nil value". This OS's own
os.*/io.*/net.*/etc. tables above are unaffected.
